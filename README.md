# Social Media App 🌐

A full-featured Social Media web application built with Next.js, Redux Toolkit, and TypeScript.

## 🚀 Live Demo
[social-media-nextjs-blond.vercel.app](https://social-media-nextjs-blond.vercel.app)

## ✨ Features
- 🔐 Authentication (Sign Up / Sign In)
- 📝 Posts (Create, Update, Delete)
- ❤️ Like & Unlike Posts
- 🔄 Share Posts
- 💬 Comments System
- 👤 Profile Management (Photo Upload, Change Password)
- 👥 Follow & Unfollow Users
- 🔍 Follow Suggestions

## 🛠️ Tech Stack
- Next.js 14
- TypeScript
- Redux Toolkit
- Material UI (MUI)
- Axios
- Formik

## 🏃 Getting Started
npm install
npm run dev
